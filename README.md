# D&D Virtual Tabletop

Ett hobbyprojekt där jag experimenterar med att bygga ett webbaserat
virtual tabletop för Dungeons & Dragons.

Projektet är fortfarande i ett tidigt utvecklingsstadium.

## Teknik

### Frontend
- React
- TypeScript
- Vite
- PixiJS

### Backend
- C#
- ASP.NET Core
- SignalR

## Funktioner hittills

- Grid-baserad spelplan
- Visning av tokens på spelplanen
- Grundläggande frontend i React/TypeScript och PixiJS
- Backend i ASP.NET Core
- Påbörjad realtidskommunikation med SignalR

## Planerade funktioner

- Drag and drop av tokens
- Snap-to-grid för tokens
- Synkronisering av tokens mellan spelare
- Persistens av spelstatus
- Fler verktyg för Dungeon Master

## Status

Projektet är ett pågående hobbyprojekt som jag använder för att lära mig
mer om React, TypeScript, realtidskommunikation och ASP.NET Core.
